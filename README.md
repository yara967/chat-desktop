# ✦ Chat Desktop com JavaFX e Groq

Aplicativo de chat desktop desenvolvido em **JavaFX**, integrado à **API da Groq** para permitir conversas com inteligência artificial.

O projeto foi desenvolvido durante o curso de **Análise e Desenvolvimento de Sistemas (ADS)**, com o objetivo de aplicar na prática conceitos de Java, JavaFX, APIs e banco de dados.

## 🚀 Funcionalidades

* 💬 Chat com inteligência artificial
* 🤖 Integração com a API da Groq
* 🔐 Sistema de login
* 📝 Cadastro de usuários
* 🗄️ Banco de dados SQLite
* 💾 Persistência de conversas e mensagens
* 📚 Suporte a RAG
* 🎨 Interface personalizada em JavaFX
* ⌨️ Envio de mensagens pelo botão ou Enter

## 🛠️ Tecnologias

* Java 20
* JavaFX 20.0.1
* Maven
* SQLite
* JDBC
* Gson
* API Groq
* FXML e CSS
